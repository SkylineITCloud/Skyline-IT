## Core Capabilities

### PCB Design
- Multi-layer PCB design (2-8 layers)
- High-speed digital design
- Analog and mixed-signal layouts
- Power electronics design
- RF design (with subcontract partners)
- Flexible/rigid-flex PCB design
- Design for Manufacturing (DFM) optimization
- IPC-2221/2222 compliant design standards

### Embedded Systems
- **Microcontrollers:** ESP32, ESP8266, STM32, ATmega (Arduino), PIC, ARM Cortex-M
- **Firmware:** Bare-metal, RTOS (FreeRTOS), Zephyr
- **Languages:** C, C++, Python, MicroPython, Assembly
- **Protocols:** SPI, I²C, UART, CAN, RS-485, I²S, PWM, ADC/DAC
- **Wireless:** Wi-Fi, Bluetooth/BLE, LoRa, Zigbee, Z-Wave, NFC

### Internet Of Things (IoT) Solutions
- End-to-end Internet Of Things (IoT) architecture design
- Sensor node development (battery-powered, low-power)
- Cloud integration (Bob Group (IoT), Bob Group (IoT), ThingsBoard, custom)
- MQTT, HTTP/HTTPS, CoAP protocol implementation
- Mobile app backend integration
- Data visualization dashboards
- OTA firmware updates

### Prototyping & Testing
- Breadboard and perfboard prototyping
- PCB prototyping (small batch)
- 3D-printed enclosure design
- Functional testing and validation
- Environmental testing (temperature, humidity)
- Power consumption analysis
- EMC pre-compliance testing (basic)

### Product Development
- Full product lifecycle management
- Concept to production support
- Component selection and BOM optimization
- Cost-down analysis
- Manufacturing partner coordination
- Quality control documentation
